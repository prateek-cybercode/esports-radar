ESPORTS RADAR — FREE STARTER APP

WHAT IT DOES
- Installable web app layout for Android.
- Quick links to esports discovery sources and Bengaluru-specific searches.
- Lets you save tournament names, game, registration deadline and link.
- Requests browser notification permission and reminds you about deadlines within 24 hours IF the app is open.

IMPORTANT LIMITATION
This starter does not automatically crawl websites or send push notifications while fully closed. Reliable background alerts require a hosted backend/push service and event-source integrations. The app does not claim that a listing is verified or local.

HOW TO USE
1. Host the contents of this folder on an HTTPS static host (for example GitHub Pages or Netlify).
2. Open the hosted URL in Chrome on Android.
3. Use Chrome menu > Add to Home screen / Install app.
4. Open the app, tap Enable notifications, and allow notifications.
5. Check the source links regularly, then save events and deadlines in the app.

FREE HOSTING
GitHub Pages and Netlify have free static hosting options. Upload the files in this folder as a static site. No API key is required.

SAFETY
- Verify organiser identity, venue, eligibility and registration deadline on the official event page.
- Do not pay entry fees to unknown organisers or share OTPs/passwords.
- Some tournament platforms list paid as well as free events; check fees before registering.
